Windows Desktop App

MediCounter

A Windows desktop app for managing medication inventory per person. The current focus is a calm, clear person-first workflow that keeps selection, overview, and daily handling easier to understand.

Windows App WinUI 3 .NET Inventory Flow Multi-Person Setup Release v0.5.0
Download Windows Build

Overview

What this project is about

MediCounter is a desktop app concept aimed at keeping medication inventory management more structured and easier to follow. Instead of a cluttered all-in-one view, the app starts with person selection and then moves into a clearer stock workflow for that specific context.

Goals

What the app should achieve

  • Make medication inventory easier to understand at a glance
  • Separate management by person instead of mixing everything into one view
  • Reduce friction in everyday use through a calmer, clearer workflow
  • Build a foundation that can grow into a stronger inventory tool later

Focus

What I wanted to get right first

  • A person-first entry point instead of a crowded opening screen
  • A desktop UI that feels direct, practical, and low-stress
  • Simple management actions before adding more advanced logic
  • A workflow that looks understandable even without a long explanation

Current Features

What is already visible in the app

  • Person selection as the main starting point
  • Add and remove actions around the selected person flow
  • A structured form area prepared for stock-related input
  • A cleaner desktop layout centered around management rather than presentation noise

Tech Stack

What this release suggests technically

  • Windows desktop application
  • WinUI 3 based user interface
  • .NET runtime distribution for x64 Windows
  • Desktop-first workflow instead of browser-based interaction

UX Direction

Why the interface direction matters here

  • A medication tool should feel clear and dependable, not visually noisy
  • Choosing the person first keeps the later information more contextual
  • A simple layout reduces the mental load during routine use
  • Desktop space can be used for structure and clarity instead of crowding controls

Next Steps

What could come next

  • Deeper inventory logic per person
  • More detailed medication entries and stock states
  • Validation, persistence, and clearer data flow
  • A more complete release beyond the current early desktop version
